แนวคิด & วัตถุประสงค์

โปรเจกต์นี้เป็นเว็บไซต์รวมเกม (Game Portal) ออกแบบในธีมทหาร/ยุทธวิธี จัดทำขึ้นเพื่อ:

  • > เรียนรู้การทำเว็บแบบ Single Page Application (SPA) ที่สลับหน้าด้วย JavaScript โดยไม่ต้องโหลดหน้าใหม่
  • > เรียนรู้การฝังเกม (embed) จากแพลตฟอร์มภายนอกด้วย iframe
  • > ฝึกออกแบบ UI/UX ด้วย CSS โดยใช้ clip-path สร้างมุมตัดสไตล์ทหาร
  • > ฝึกเขียนระบบโต้ตอบ (login, คลังแสง, แบบทดสอบ) ด้วย Vanilla JavaScript

โครงสร้างระบบ (Architecture)

เว็บไซต์นี้แบ่งออกเป็น 4 ส่วนหลัก:

  • [01] ระบบเข้าสู่ระบบ
    หน้า Login / สมัครสมาชิก
  • [02] หน้าหลัก
    หน้าแรกและเมนูนำทาง
  • [03] หน้าเล่นเกม
    ฝังเกมด้วย iframe
  • [04] แบบทดสอบ
    แบบทดสอบความรู้แบบโต้ตอบ

โค้ด & เทคโนโลยีที่ใช้

HTML5 / Iframe

iframe ช่วยแยกเกมออกจากหน้าเว็บหลัก ทำให้ปลอดภัยและไม่กระทบกับส่วนอื่นของเว็บ

Tailwind CSS & Clip-path

ใช้ Tailwind จัดการ layout และเขียน CSS เพิ่มเติมด้วย clip-path เพื่อสร้างมุมตัดตามธีมทหาร

Vanilla JS

ใช้ควบคุมระบบ login, การสลับหน้าแบบ SPA, และคำนวณคะแนนในแบบทดสอบ

SPA_Router.js
// ฟังก์ชันสลับหน้าแบบไม่ต้องรีเฟรช
function showPage(pageName) {
    document.querySelectorAll('.page-view').forEach(p => {
        p.classList.remove('active');
    });
    document.getElementById('page-' + pageName).classList.add('active');
}
